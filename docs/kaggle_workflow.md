# Kaggle API Workflow & CLI Sync Guide

This guide explains how to authenticate the Kaggle CLI and download output artifacts (including `submission.zip`) directly from your running Kaggle kernels into your local project environment.

---

## 1. Setup Your Kaggle API Token (`kaggle.json`)

To use `kaggle` from the Command Prompt (CMD), PowerShell, or WSL, you need your Kaggle API key:

1. Log in to [Kaggle](https://www.kaggle.com).
2. Click your profile picture in the top-right corner and select **Settings** (or visit [kaggle.com/settings](https://www.kaggle.com/settings)).
3. Scroll down to the **API** section and click **"Create New Token"**.
4. A file named **`kaggle.json`** will be downloaded to your computer.

### Where to Place `kaggle.json`:

* **For Windows CMD & PowerShell**:
  Place the file at:
  ```text
  C:\Users\gbhan\.kaggle\kaggle.json
  ```
  *(If the `.kaggle` folder doesn't exist, create it: `mkdir C:\Users\gbhan\.kaggle`)*

* **For WSL / Linux / Virtualenv**:
  You can also place a copy inside the project repository:
  ```text
  D:\1-Projects\1-Verifiable-Quantum-Circuit\.kaggle\kaggle.json
  ```
  *(Note: `.kaggle/` is already in `.gitignore` so your private API key is never committed to GitHub).*

---

## 2. Exporting Outputs from Kaggle to Local System

Once `kaggle.json` is in place, you can download the generated `submission.zip` and circuit dumps using any of the methods below:

### Option A: From Windows Command Prompt (CMD)

```cmd
kaggle kernels output gbhanuteja23/notebook2d8aff629d -p D:\1-Projects\1-Verifiable-Quantum-Circuit\data\kaggle_outputs
```

### Option B: From Linux / WSL Terminal

```bash
# Activate the virtual environment
source /mnt/d/1-Projects/1-Verifiable-Quantum-Circuit/.venv/bin/activate

# Export kernel outputs to local directory
export KAGGLE_CONFIG_DIR=/mnt/d/1-Projects/1-Verifiable-Quantum-Circuit/.kaggle
kaggle kernels output gbhanuteja23/notebook2d8aff629d -p data/kaggle_outputs
```

### Option C: Using the Project Sync Helper Script

We have provided a dedicated Python helper in `scripts/kaggle_sync.py` that automatically finds your credentials:

```bash
# Export outputs:
python scripts/kaggle_sync.py output gbhanuteja23/notebook2d8aff629d -p data/kaggle_outputs

# Check kernel execution status on Kaggle:
python scripts/kaggle_sync.py status gbhanuteja23/notebook2d8aff629d

# Pull the latest notebook from Kaggle:
python scripts/kaggle_sync.py pull gbhanuteja23/notebook2d8aff629d -p notebooks/
```

## 3. What Gets Downloaded

When you run `kaggle kernels output`, Kaggle downloads all files generated by the notebook in `/kaggle/working/`:
* `submission.zip` (The official submission archive)
* `invsqrt.kmx` (Benchmark I circuit)
* `dqi.kmx` (Benchmark II circuit)
* `dfthcsos/` (Benchmark III circuits & `submission.npz`)
